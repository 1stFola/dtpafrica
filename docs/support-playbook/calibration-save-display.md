# Calibration Save Or Display Issue

Tier: Tier 1 - Known issue recommendation

## Symptoms

- Height or weight does not display on the public profile.
- Benchmark selection appears unchanged.
- Ratings save but profile facts look wrong.

## Diagnose

- Use height formats such as `5'11"` or `180cm`.
- Confirm weight is numeric kilograms.
- Reload calibration context after saving.

## Recommendation

Re-save with valid values, then check the public profile. Escalate if stored database values differ from the save payload.
