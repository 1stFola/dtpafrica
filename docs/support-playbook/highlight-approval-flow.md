# Highlight Approval Flow

Tier: Tier 1 - Known issue recommendation

## Symptoms

- Upload succeeds with `queued unpublished`.
- Supervisor cannot approve highlights.
- Video or photo card does not appear publicly.

## Diagnose

- Check highlight `isPublished`.
- Confirm media URL normalization.
- Confirm admin user has highlight permissions.

## Recommendation

Use the supervisor/highlights review control to approve after confirming match and media context.
