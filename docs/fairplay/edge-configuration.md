# FairPlay Edge — configuration reference

Every setting the Edge reads, with its default and where it is set (Phase 6.1). Installing is
in [edge-install.md](./edge-install.md).

**Where settings live:**
- **`.env`** holds the Edge's settings and secrets, and also sets Compose's own variables.
- **`publish.env`** holds the cameras' publish passwords.
- **Compose and the image** set the container's internal paths and addresses. Leave those
  alone.

`deploy/install.sh` writes `.env` and `publish.env` from the committed examples and
generates every secret. `tests/test_configuration_reference.py` fails if a setting the code,
Compose or an example reads is missing here, or if one listed here is read nowhere.

The Edge **refuses to start** in four cases:
- a secret is missing, shorter than 24 characters, or still a placeholder;
- the camera network list is empty;
- the API is bound beyond this machine without TLS;
- a cloud URL is not https.

## Secrets

| Variable | Default | What it is | Set in |
|---|---|---|---|
| `FAIRPLAY_EDGE_API_TOKEN` | none (required) | The device token for the Edge's own API: `fairplay-edge api`, the container's health check, scripts. Generated by the installer. | `.env` |
| `FAIRPLAY_MEDIAMTX_PASSWORD` | none (required) | The password the Edge uses for MediaMTX's API and playback. Generated by the installer. | `.env` |
| `FAIRPLAY_MEDIAMTX_USER` | `fairplay-edge` | The user name for MediaMTX's API and playback. | `.env` |
| `FAIRPLAY_PUBLISH_PASSWORD_<SOURCE>` | none (required per source) | The password a camera or encoder publishes with, one per source in `sources.toml` (`GROUND`, `DRONE`, ...). Generated by the installer. | `publish.env` |
| `FAIRPLAY_CLOUD_DEVICE_TOKEN` | none | The cloud device token, if not read from a file. | `.env` |
| `FAIRPLAY_CLOUD_DEVICE_TOKEN_FILE` | none | The file `fairplay-edge pair` wrote the device token to (preferred). | `.env` |

## Exposure and network

| Variable | Default | What it is | Set in |
|---|---|---|---|
| `FAIRPLAY_EDGE_HOST_BIND` | `127.0.0.1` | The host address the console and API are published on. Anything but loopback needs both TLS settings. | `.env` (installer: `--lan-ip`) |
| `FAIRPLAY_EDGE_TLS_CERT` | none | The Edge's server certificate. `tls-init` writes `/var/lib/fairplay/data/tls/server.pem`. | `.env` (installer) |
| `FAIRPLAY_EDGE_TLS_KEY` | none | Its private key, `server-key.pem`. | `.env` (installer) |
| `FAIRPLAY_EDGE_HOSTNAMES` | the certificate's names, and localhost | With TLS, the only host names the Edge answers to (F19). | `.env` |
| `FAIRPLAY_EDGE_PORT` | `8443` | The port the Edge listens on, and `fairplay-edge api` calls. | `.env` |
| `FAIRPLAY_INGEST_BIND` | `127.0.0.1` | The host address cameras publish RTSP to (port 8554): the Edge's camera-network address. | `.env` (installer: `--ingest-ip`) |
| `FAIRPLAY_PUBLISH_ALLOWED_CIDRS` | none (required) | The networks cameras may publish from. MediaMTX refuses any other source address. | `.env` (installer: `--cameras`) |
| `FAIRPLAY_UPLOAD_HOSTS` | `*.r2.cloudflarestorage.com` | The hosts presigned evidence uploads may go to (F9). | `.env` |
| `FAIRPLAY_CLOUD_SYNC_URL` | none (nothing leaves the Edge) | The DTP cloud API. https only. | `.env` |

## Recording and the watchdog

| Variable | Default | What it is | Set in |
|---|---|---|---|
| `FAIRPLAY_RECORD_SEGMENT_DURATION` | `5m` | The length of each recording file. | `.env` |
| `FAIRPLAY_RECORD_PART_DURATION` | `1s` | The length of each part: the most an abrupt stop loses. | `.env` |
| `FAIRPLAY_FINALIZE_QUIET_SECONDS` | `10` | A closed feed's last file is finalised after this many quiet seconds. | `.env` |
| `FAIRPLAY_RECORD_STALL_SECONDS` | `6` | Publishing with nothing written for this long raises `recording_stalled`. | `.env` |
| `FAIRPLAY_POLL_SECONDS` | `2` | How often the watchdog and the scanner run. | `.env` |
| `FAIRPLAY_DISK_SOFT_FREE_GB` | `20` | Below this free space: `disk_soft_limit`. | `.env` |
| `FAIRPLAY_DISK_HARD_FREE_GB` | `5` | Below this: `disk_hard_limit`, and new sessions, clips and exports are refused. | `.env` |
| `FAIRPLAY_DISK_FULL_FREE_MB` | `64` | Below this: `disk_full`; no camera is shown as recording. | `.env` |
| `FAIRPLAY_CLIP_MAX_ATTEMPTS` | `3` | Tries for each evidence clip before the job fails. | `.env` |

## Time and the match

| Variable | Default | What it is | Set in |
|---|---|---|---|
| `FAIRPLAY_CLOCK_MAX_ERROR_MS` | `1000` | Past this kernel maximum error, the clock counts as drifting. | `.env` |
| `FAIRPLAY_CLOCK_SETTLE_SECONDS` | `120` | How long "not synchronised" must last before it is reported. | `.env` |
| `FAIRPLAY_CALIBRATION_CONFIRM_MS` | `5000` | A calibration offset above this must be confirmed. | `.env` |
| `FAIRPLAY_PERIOD_MINUTES` | `45` | The length of a half, for the match clock (10 to 60). | `.env` |
| `FAIRPLAY_EXTRA_PERIOD_MINUTES` | `15` | The length of an extra-time period (5 to 30). | `.env` |

## Retention

| Variable | Default | What it is | Set in |
|---|---|---|---|
| `FAIRPLAY_RETENTION_DAYS` | none (off) | Delete recordings older than this many days. Never deletes held footage, or footage behind evidence not yet synced. D9 says 14. | `.env` |
| `FAIRPLAY_RETENTION_MAX_DELETIONS` | `50` | The most files one retention run deletes. | `.env` |

## Sign-in and identity

| Variable | Default | What it is | Set in |
|---|---|---|---|
| `FAIRPLAY_DEVICE_LABEL` | `edge` | This Edge's name, shown on the sign-in page and in reports. | `.env` (installer: `--label`) |
| `FAIRPLAY_TRUSTED_KEYS_FILE` | none | The public keys an operator bundle must be signed by. | Compose (`./auth/trusted-keys.json`, read-only) |
| `FAIRPLAY_BUNDLE_FILE` | none | Where the operator bundle is read from. | Compose, from `FAIRPLAY_BUNDLE_PATH` |
| `FAIRPLAY_ALLOW_DEV_BUNDLES` | off | `1` accepts DEV bundles: development and rehearsal only. | `.env` |

## Set by Compose and the image (leave alone)

| Variable | Default | What it is | Set in |
|---|---|---|---|
| `FAIRPLAY_DATA_DIR` | `/var/lib/fairplay/data` | The database, manifests, evidence, exports, TLS, backups. | the image |
| `FAIRPLAY_RECORDINGS_DIR` | `/var/lib/fairplay/recordings` | MediaMTX's recordings. | the image |
| `FAIRPLAY_SOURCES_FILE` | `/etc/fairplay/sources.toml` | The sources. | the image |
| `FAIRPLAY_IN_CONTAINER` | none | `1` inside the image: the container's own listen address is not the host's exposure. | the image |
| `FAIRPLAY_EDGE_LISTEN` | the host bind | The address the API listens on inside the container (`0.0.0.0`). | Compose |
| `FAIRPLAY_EDGE_IP` | `127.0.0.1` | The Edge's address on the stack's network, the only one MediaMTX's API accepts. | Compose (`172.31.250.10`) |
| `FAIRPLAY_MEDIAMTX_API_URL` | `http://127.0.0.1:9997` | MediaMTX's API, never published. | Compose |
| `FAIRPLAY_MEDIAMTX_PLAYBACK_URL` | `http://127.0.0.1:9996` | MediaMTX's playback server, never published. | Compose |
| `FAIRPLAY_MEDIAMTX_HLS_URL` | `http://127.0.0.1:8888` | MediaMTX's HLS server, for the live preview, never published. | Compose |
| `FAIRPLAY_CONSOLE_DIR` | none | The built console, served on the Edge's origin. | Compose (`/srv/console`) |
| `FAIRPLAY_SYNTH_TARGET` | `mediamtx:8554` | Where a synthetic test feed publishes. Development only. | Compose (`synthetic` profile) |

## Compose's own variables (in `.env`)

| Variable | Default | What it is |
|---|---|---|
| `FAIRPLAY_EDGE_TAG` | `local` | The Edge image tag. The installer and `update.sh` pin it to `<version>-<commit>`. |
| `FAIRPLAY_BUNDLE_PATH` | `/etc/fairplay/auth/bundle.json` | Where the bundle is. A paired Edge needs `/var/lib/fairplay/data/bundle.json`, so it can write the cloud's. |
| `FAIRPLAY_ENV_FILE` | `.env` | The settings file the containers read. Tests and drills only. |
| `FAIRPLAY_PUBLISH_ENV_FILE` | `publish.env` | The publish passwords file. Tests and drills only. |
| `FAIRPLAY_SOURCES_PATH` | `./config/sources.toml` | The host's sources file. |
| `FAIRPLAY_CONSOLE_PATH` | `../../apps/fairplay-console/dist` | The host's built console. |
| `FAIRPLAY_AUTH_DIR` | `./auth` | The host folder with `trusted-keys.json` (and a DEV bundle). |
